Accessibility — Undercut

An honest statement, not a certificate.

Our target for this site (getundercut.sh) is WCAG 2.1 Level AA. We've fixed the specific issues an audit found, and we're saying plainly what we have and haven't checked. This is not a claim of full conformance, a VPAT, or sign-off from an accessibility audit firm — none of those exist for this site.

What's been verified and fixed

A round-3 accessibility pass on the landing page found and we fixed:

  • Text contrast. The signal-green and escalate-amber text used for the calculator's savings percentage, vendor-comparison rows, tier labels, and budget/hard-stop copy measured 2.96–3.41:1 against their light backgrounds — below the 4.5:1 minimum for normal text. Darker text-only variants (#227644, #955D22) now carry those instances. Button backgrounds and large/bold headline uses, which already passed, were left alone.
  • Accessible names on form inputs. Five inputs had none: three placeholder-only email fields (hero, calculator footer, pricing card) now have aria-label; the two calculator number inputs (Seats, Spend) are now paired with their visible labels via id/for.
  • Native semantic controls. Buttons and links use native <button> and <a> elements rather than divs with click handlers, so they carry correct roles, keyboard focus, and Enter/Space activation for free.

What hasn't been formally audited

This is a small team shipping fixes as they're found, not a completed compliance program. Specifically not yet done:

  • Full screen-reader testing (VoiceOver, NVDA, JAWS) across every page and interactive flow.
  • Comprehensive keyboard-navigation testing beyond the native controls above — focus order, visible focus states, and trap avoidance across the whole page haven't been walked end to end.
  • Color contrast on every remaining UI element, not just the instances flagged in the round-3 pass.
  • Testing with browser zoom, reduced-motion settings, or assistive input devices.
  • A formal WCAG 2.1 AA conformance audit by a third party, or a VPAT. Neither exists for this site.

Report an issue

If something on this site is hard to use with a screen reader, keyboard only, or any other assistive technology, tell us — open a GitHub issue. We'll treat accessibility bugs like any other bug.
