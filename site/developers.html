Developers — Undercut

No public API or MCP server yet — here's what actually exists.

Honest status: there is no hosted API, no MCP server, and no SDK. The free tier is SKILL.md — a policy file your agent reads locally. There are no endpoints to call.

What exists today

Undercut ships as a single MIT-licensed skill file, not a service:

  • skills/firstpass/SKILL.md — the routing policy itself, plain text, readable by any agent that follows a SKILL.md convention (Claude Code, Codex, Cursor, Copilot, OpenCode).
  • github.com/undercutsh/firstpass — the full source: the skill, the eval harness in evals/, raw benchmark data in testing/results/, and this site.

Install it by copying the skill into your agent's skills directory, or:

npx skills add undercutsh/firstpass

That's it — no account, no API key, no network call to us. Nothing here phones home.

What doesn't exist yet

No hosted routing API. No MCP server. No SDK or client library. No webhook or telemetry endpoint. There is a first-party @undercut/cli package in this repo's cli/ directory, but it's a structural scaffold, not a published API: status and logout work today with no network calls, while login and sync are real control flow pointed at a backend that hasn't shipped yet, and it isn't published to npm. Full honesty write-up: getundercut.sh/cli.md.

What's planned

Undercut's paid tiers — Pro's pooled vetting ledger and hosted dashboard, and Teams' org-wide policy enforcement, shared dashboard, and seat management — are the most likely place an API or MCP server would eventually live, since that's where server-side state (usage, ledgers, org policy) actually needs to exist. Teams is sold today through founder-run onboarding, not a self-serve API; no public interface is built yet, and nothing here should be read as a commitment to a specific interface or timeline. Pro does already make one authenticated request the free tier doesn't: a periodic policy-file sync, not a routing API and not a telemetry endpoint. Exactly what it reveals: What we can see.

The place to be when that ships is on a paid tier: start a Pro trial or Teams onboarding.

In the meantime

The most useful thing you can do as a developer today is read the policy file, run the eval harness yourself, or open an issue/PR against the repo:

  • Raw SKILL.md
  • Eval harness + methodology (testing/README.md)
  • AGENTS.md — build/test commands and repo conventions
  • Issues
