Your setup

What Undercut actually unlocks depends on your editor and your keys. Two questions, then the honest answer.

The routing skill is the same file everywhere — free, MIT, no account. How much it can save you is not the same everywhere: it depends on which models your tool lets it route between. Some setups reach every tier. One reaches a single vendor's ladder. We'd rather tell you which is which before you install than have you find out after.

The four setups

Every one of these is the same free skill. What differs is how many model tiers your tool lets it route between — and whether there's a cheap, low-friction way to reach more.

Setup AClaude Code + a Claude subscription

Real savings, inside one vendor's ladder. Not the biggest ones.

This is the setup with the lowest ceiling, and we'd rather say so here than let you infer it after installing. Claude Code talks to Anthropic's models. With a Claude Pro or Max subscription, Undercut routes each unit of work up and down Anthropic's own tier ladder — Haiku, Sonnet, Opus, Fable — and nothing else.

What Undercut does for you

  • Stops mechanical work from running at Opus-or-above by default. The six-flag rubric still catches over-escalation inside Anthropic's ladder — that's a real, measured effect, not a rounding error.
  • Measured on Anthropic's ladder alone: −61% cost on HumanEval at the same pass rate, −4% on GSM8K — the smallest of the four vendor families we benchmarked (the data).
  • When Pro ships, its pooled model testing and effort-level tuning apply to Anthropic's tiers specifically — the same bounded scope, kept current for you.

What it can't reach here

  • The biggest dollar swings. Open-weight tiers cost pennies per task where Anthropic's tiers cost dollars; Claude Code with subscription auth can't route to them at all.
  • Any other vendor. Claude Code's subscription auth and an API key or proxy are mutually exclusive per session — you can't add a second vendor alongside the plan.
  • There is an unofficial proxy workaround (ANTHROPIC_BASE_URL). We don't recommend it: it's a gray area under Anthropic's terms, fragile, and could stop working without notice.

The honest recommendation

Install the free skill. It's a bounded win, but it is a win, and it costs nothing — no key, no account, nothing on the network path.

If cross-vendor savings matter more to you than subscription pricing for Claude, the honest path isn't a workaround — it's a tool that accepts your own keys (Setup C below). The tradeoff is real and worth stating plainly: you'd give up flat-rate subscription pricing for Claude in exchange for full routing flexibility across every vendor and tier. For some workloads that trade pays; for others it doesn't. We can't tell you which from here, and we won't pretend to.

What Undercut does for you

  • Routes each unit of work to the cheapest tier that can pass verification across every model your picker already offers — instead of one model for the whole session.
  • Escalates on evidence only. A wrong flag costs one extra cheap attempt, never a wrong answer or a big bill.

What it doesn't change

  • What your subscription includes. The multi-vendor frontier-lab access was yours before Undercut and stays exactly as it was.
  • Your quota math. BYOK calls run on a separate, separately-billed track in all three tools; the skill doesn't move subscription-included calls off it.
  • Nothing here is a proxy. It's a policy file the agent reads; remove it and you're back to status quo.

Add an OpenRouter key — to unlock a tier your subscription doesn't have

Optional

This is not a general "add a key" instruction, and the free skill works without it. It's specifically the one low-friction move that puts the open-weight cheap tier in reach: one API key, pasted into your tool's BYOK settings, no OAuth. Open openrouter.ai, create a key, then find the bring-your-own-key section in your tool's settings (Cursor and Copilot document theirs; for Windsurf, see the caveat above) and paste it in. The skill picks up the new tier through models.md's open-weight column.

One caveat we publish everywhere: open-weight price ladders can invert — a vendor's "standard" tier is sometimes cheaper than its "cheap" one. Check the provider's price list rather than assuming cheap is cheapest.

Why this page exists

A routing skill that oversells itself to the people it can't help isn't worth trusting on the people it can.

The benchmark numbers on the landing page are real and reproducible. They're also measured within a vendor, and the biggest ones come from vendors and tiers that not every tool can route to. Rather than average that into one headline, this page tells you which case you're in.
