Privacy — Undercut

We don't track you. Literally.

This site (getundercut.sh) is a static page. It sets no cookies, runs no analytics, and sells or shares no personal information — there is simply nothing tracking you while you're here. The tool itself is downloaded by your agent and runs locally; it does not phone home.

What we do handle

  • GitHub activity. If you star or open issues on the repository, that data lives on GitHub under GitHub's privacy policy, not ours.
  • Benchmark runs. The eval harness (evals/) calls model providers directly to measure routing. If you run it yourself, those calls are made under whatever provider account you use — we never see them.
