Privacy — Undercut

We don't track you. Literally.

This site (getundercut.sh) is a static page. It sets no cookies and runs no analytics — there is no tracker following you around while you're here. A few pages make plain, unauthenticated calls to GitHub's public API to show live data (details below), and if you use a form on this site your email goes exactly where we say it goes. Nothing is sold. The tool itself is downloaded by your agent and runs locally; it does not phone home.

What we do handle

  • GitHub activity. If you star or open issues on the repository, that data lives on GitHub under GitHub's privacy policy, not ours.
  • Live GitHub API calls from your browser. The "★ stars on GitHub" chip in the footer (every page) and the /status page both make an unauthenticated GET request directly from your browser to api.github.com (public repo/stargazer counts, public Actions run history). No cookie, account info, or anything identifying you is attached — just the standard headers your browser sends on any request. That request, and whatever GitHub logs from it (e.g. your IP address, per GitHub's own privacy policy), happens between your browser and GitHub directly; we don't see or store it. The star count is cached in your browser's sessionStorage for an hour, on your device only.
  • Lead-capture forms. The "Email me my audit" and "Get early access" (Teams waitlist) forms send your email — plus, for the audit form, non-identifying calculator inputs (individual/team mode, vendor, seat count, spend) — to our /api/lead endpoint. That endpoint validates the submission (allowed fields only, size-capped) and forwards it as JSON to a webhook URL the site operator configures — an email or spreadsheet automation tool — so we can send you your audit or add you to the waitlist. If no webhook is configured, submissions are rejected outright, not silently dropped. We don't sell this data or hand it to anyone beyond that configured destination.
  • Benchmark runs. The eval harness (evals/) calls model providers directly to measure routing. If you run it yourself, those calls are made under whatever provider account you use — we never see them.
