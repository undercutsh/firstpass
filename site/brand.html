Name

The product is Undercut. One word, capital U, no styling — not UnderCut, not undercut.sh, not Undercut.ai. Lowercase undercut is correct only when it is set in the wordmark itself or appears in a command, path or package name.

The free skill that the product is built around is first-pass in prose and firstpass as an identifier, which is also the name of the open-source repository. The two are not interchangeable: Undercut is the product, first-pass is the skill file.

Undercut runs every unit of work at the cheapest model that can pass verification.

Short paragraph

Undercut is a free, MIT-licensed SKILL.md that coding agents follow at dispatch time. A six-flag rubric assigns each unit of work a base model tier, and only objective evidence — a failed verification, a measured disagreement between two cheap-tier attempts, or an explicit uncertainty flag — can escalate it. It is a local policy file, not a proxy: it never sits on the network path between an agent and its model provider.

Cost and pass-rate figures change as benchmarks are re-run, so please take any number from the landing page or the benchmark methodology at the time of writing rather than from an older article. Every claim traces to a public, reproducible harness with deterministic graders.

Using the marks

  • Do keep clear space around the mark equal to the height of one bar.
  • Do place the mark on #f2f0ec, #fbfaf8, #1c2027 or white. On any other ground, use the single-colour version in #13161b or #f2f0ec.
  • Do scale it no smaller than 20 px tall for the logomark, 120 px wide for the lockup.
  • Don't recolour the mark outside the palette below, add effects, outline it, or rotate it.
  • Don't stretch, condense or rebuild the lockup — the spacing is part of the mark.
  • Don't set the mark over a photograph, or over the bright side of one.

Typography

Bricolage Grotesque sets everything that is read as language — headlines, body copy, buttons. Fragment Mono sets everything that is read as data — labels, figures, code, terminal output, eyebrow text. Both are open-licensed and available from Google Fonts, so you can reproduce a page without asking us for a font file.

Headlines run at weight 500 with tight tracking (about −0.03 em). Body copy is weight 400 at a 1.6–1.65 line height. Mono labels are uppercase, 11–12 px, tracked out about 0.08 em. If you only take one rule: language in the sans, numbers in the mono.

Photography

Where we use photography it is warm daylight, one subject, one action, and a great deal of empty space — documentary rather than staged. No neon, no holograms, no glowing interfaces, no circuitry. If you are producing something co-branded and want the full direction, including the camera and lighting specification, ask and we will send it.
